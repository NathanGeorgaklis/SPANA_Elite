## Truth (pending)

- Schema: `r2_jersey_labels_v1` (`tools_rb/r2_jersey_labels.py`).
- Guide: `JERSEY_LABELLING_GUIDE.md`.
- Page: `tools_rb/r2_jersey_annotator.html`.
- Per 0.5 s keyframe:
  - target box;
  - VISIBLE / PARTIAL / HIDDEN / OUT_OF_FRAME;
  - READABLE / UNREADABLE + reason;
  - HUMAN_UNCERTAIN.
- Per clip: expected number (null = never visible) and same-kit competitor numbers with readable keyframes.
- **Freeze:** `python3 tools_rb/r2_jersey_labels.py freeze LABELS R2/JERSEY_DATASET/JERSEY_CLIP_REGISTRY.json
  R2/labels/jersey_dataset [REASON]`.
  - Byte-for-byte read-only copy `<clip>.jersey.v<N>.FROZEN.json`, plus a freeze record with its sha256.
  - Checks: the registry (clip hash, fps, frames, source image size), the DEV split (registry and protocol), and every
    schema rule.
  - Never overwrites. A correction is v<N+1>, needs a reason and names what it supersedes; old versions are kept.
- **Record:** `... record R2/labels/jersey_dataset R2/JERSEY_DATASET/JERSEY_CLIP_REGISTRY.json`.
  - Uses the latest version per clip, checks every file against its freeze record, and fails closed if a clip is
    missing.
  - Gives the dataset sha256 and coverage: readable / unreadable / not visible / human-uncertain keyframes, reasons,
    never-visible clips, same-kit competitor numbers, duplicate numbers.
- **Reader evaluation design:** reads must crop the **human** target box on the same keyframe grid, so OCR is
  measured apart from tracker identity. HUMAN_UNCERTAIN and rejected material is reported separately, never silently
  dropped. To be preregistered before any reader runs.
